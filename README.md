# Vithal Technology - Official Website

Official website for **Vithal Technology Private Limited** hosted seamlessly on **GitHub Pages**.

## Overview
This website highlights Vithal Technology's capabilities in custom software engineering, AI agent implementations, cybersecurity solutions, IoT telemetry, and electronic device concepts.

## Features
- **Cinematic Entry Animation**: Custom glowing energy rings and intro text with reduced-motion support.
- **Glassmorphism Theme**: Cyber-futuristic dark mode theme using cyan neon and blue highlights.
- **Vithal AI Frontend Assistant**: Intelligent Assistant understanding English, Hindi, Hinglish, and Marathi.
- **WhatsApp Integration**: Instant custom message links for services and products.
- **GitHub Pages Ready**: Standard HTML5, CSS3, Vanilla JavaScript with relative paths.

## Setup Instructions
1. Clone this repository to your computer or GitHub account.
2. Upload your official logo file to `assets/logo.png`.
3. Enable GitHub Pages:
   - Navigate to **Settings** > **Pages**.
   - Select **Branch: main** and **Folder: / (root)**.
   - Save changes.
